# Adam N Eve Admin Portal

Standalone Admin Dashboard and Operations Console for Adam N Eve Matrimony and Bookstore Operations.

## Tech Stack
- Next.js 15 (App Router)
- React 19
- Tailwind CSS
- Lucide Icons

## Features
- Candidate moderation & photo approval pipeline
- Printable biodata dossier generator
- Bookstore order management (with 5 features: Cover thumbnails, COD Box, 1-Click WhatsApp automation, Shiprocket push, Courier pills)
- Real-time revenue telemetry & member CRM
